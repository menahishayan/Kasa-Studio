Everything a DP actually wants from a lighting console

Built to feel like a proper lighting-control app — not a smart-home gadget toy.

◈

Auto-discovery

Every Kasa bulb on your LAN shows up on its own — no manual IP entry, no app-store account.

✎

Label every fixture

Rename "TP-LINK_Smart Bulb_018E" to "Key Light — Softbox L" so your set actually makes sense.

◎

Identify on demand

One tap blinks the physical bulb, then restores its exact prior state — find any fixture instantly.

▤

Groups & master control

Build Key / Fill / Rim / Background groups and drive power, intensity, and temp for the whole group at once.

Get it running in under a minute

Requires Node.js and Kasa bulbs on the same local network.

  1. 1

    Clone the repo

    git clone https://github.com/menahishayan/Kasa-Studio.git
cd Kasa-Studio
  2. 2

    Install and run

    npm install
npm start
  3. 3

    Open the console

    http://localhost:4173

    The terminal also prints a LAN address for pulling it up on your phone.
